# Streakly - Premium Habit Tracker

A small, dependency-free habit tracker with a dark premium UI: gradient headline,
glassmorphism panels, glow accents, animated progress rings and a five-week heatmap.

## Features

- Add and delete habits with a pickable accent colour
- One-tap daily check-in with instant progress rings
- Five-week heatmap per habit plus streak counters
- Momentum insights: completion rate, perfect days, total check-ins
- Data persists in browser localStorage - no backend, no tracking
- Responsive from 360px up, semantic HTML with ARIA labels

## Stack

Vanilla HTML, CSS and JavaScript. No frameworks, no CDN, no build step.

## Files

    index.html
    css/styles.css
    js/main.js

## Run locally

Open index.html in any modern browser.
